# Day 9 — Retail Demand Intelligence Dashboard

## 🎯 Objective

Build an interactive dashboard to analyze retail sales trends, compare store performance, and explore inventory-related metrics using Python.

## 🛠️ Tech Stack

* **Python** — Core programming
* **Pandas** — Data manipulation and analysis
* **Streamlit** — Interactive dashboard development
* **Plotly** — Interactive data visualizations

## ✅ Work Completed

### 1. Sales Overview

Created KPI cards to display:

* Total units sold
* Number of products
* Number of stores
* Average units per row

### 2. Interactive Dashboard Filters

Added sidebar filters to explore data based on:

* Date range
* Product category
* Store

These filters allow users to analyze different subsets of the data.

### 3. Sales Trend Analysis

Created a daily sales trend visualization to identify changes and patterns in sales over time.

### 4. Inventory Optimization

Developed an inventory analysis section displaying:

* Total demand
* Fulfilled demand
* Unmet demand
* Overall fill rate

Also added a bar chart highlighting the 15 products with the highest unmet demand.

### 5. Store Performance Analysis

Created a store-level sales comparison chart to identify differences in sales performance across stores.

## 📊 Key Learnings

* Building interactive dashboards with Streamlit.
* Connecting data analysis with visual reporting.
* Using filters to make visualizations more interactive.
* Presenting sales and inventory KPIs in a business-friendly format.
* Understanding how data visualization can support retail decision-making.

## 🚀 Outcome

Successfully developed a functional **Retail Demand Intelligence Dashboard** with sales analysis, interactive filters, inventory optimization metrics, and store performance visualizations.
